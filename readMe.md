# Craig Burke — Developer Portfolio 💻

**A personal portfolio website built with React and Sanity CMS.**

This project showcases my experience in frontend development, component-based interface design, animation, and content management integration.

I developed the portfolio using React for the frontend and Sanity as a headless content management system, allowing project information and other portfolio content to be managed separately from the interface code.

**Technologies:** React · JavaScript · Sanity CMS · Framer Motion · SCSS · HTML · CSS

## 🛠️ Technical Overview

### React Frontend

The frontend is built using React with a component-based architecture.

The application includes sections for:

- Header and navigation
- About
- Portfolio projects
- Skills
- Testimonials
- Contact information

Framer Motion provides animation capabilities, while SCSS is used for interface styling.

### Sanity Content Management

Sanity CMS provides the content-management layer.

The backend includes content schemas for projects, skills, experience, education, testimonials, and other portfolio information.

The React frontend connects to Sanity using its JavaScript client and image URL utilities.
